# AgentAura — demo video script

**Length:** 2:30 · **Format:** screen recording + voiceover (or burned-in
captions if you'd rather not record audio). Every shot is a real product
action — nothing is staged — so one rehearsal is enough to record it in one
take.

**Before recording (10 minutes, once):**

1. Stop the dev server → `npm run db:reset` → start it. You land on the
   Welcome screen exactly as a fresh user would.
2. Close extra tabs. Browser zoom 100%, hide the bookmarks bar.
3. Record at **1440×900** or larger; clean desktop wallpaper.
4. Have the Wallet page ready in a second tab for shot 6 (it makes the
   balance drop visible in one click).

---

that wall into a purchase order on OKX AI.*

## Edit notes

- **Cuts:** hard cuts on the beat; no crossfades except shot 1 → 2.
- **Zoom punches** (120% for ~2s) on: the banner (shot 5), the txHash + balance
  drop (shot 6), the verification score (shot 7).
- **Captions:** if no voiceover, burn the "Say this" column as lower-thirds.
- **Music:** light, low; duck under voiceover. Kill it for the banner moment —
  the silence sells the pause.
- **End card (3s, optional):** repo URL + "Built for the OKX AI Hackathon ·
  x402 · X Layer testnet".

## If something misbehaves while recording

- Hire expires (took >120s to approve): the engine falls back to internal
  execution and the mission still completes — narrate it as the resilience
  feature it is, or cut to the next shot.
- LLM planner is slow/503: the deterministic planner takes over silently;
  nothing on screen breaks. Keep rolling.
- Anything else: the event feed only shows real events, so worst case is a
  quieter feed — never a wrong one.
